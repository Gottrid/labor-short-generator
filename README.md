# Labor-Short-Generator

Web-App für den GTA-6-Kanal **Leonida Labor**: Konsolen-Clips rein, Labor-Short raus.
9:16, 61–90 Sekunden, bereit für TikTok, Instagram Reels und YouTube Shorts.

## Was die App macht

- Findet in den Clips die Stellen mit der meisten Bewegung und dem lautesten Ton
- Schneidet daraus automatisch: Hook im Vollbild, Versuchsaufbau, Messungen mit Rangliste, Countdown, Stempel, Frage am Ende
- Untertitel aus dem Sprechtext, optional mit eigener Sprachaufnahme
- Speichert das Video über das Teilen-Menü (iPhone: „Video sichern“) oder als Download
- KI-Texte: ohne Schlüssel per Copy-and-Paste mit der Claude-App, mit eigenem Anthropic-Schlüssel direkt
- Läuft nach dem ersten Öffnen auch offline

## Auf den Homebildschirm

1. Seite in **Safari** öffnen
2. Teilen-Knopf → **Zum Home-Bildschirm**

## Veröffentlichen mit GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch `main`, Ordner `/ (root)` → Save.
Nach etwa einer Minute ist die App unter `https://<nutzername>.github.io/<repo>/` erreichbar.

## Datenschutz

Alle Videos bleiben auf dem Gerät. Ein optionaler KI-Schlüssel wird nur lokal im Browser gespeichert.
